# Changelog

## 0.2.0

- Rename the app to eFootball Net.
- Put live readings and the UDP chart under Monitor.
- Put session review and comparisons under History in the same window.

## 0.1.0

- Monitor eFootball UDP flows with Windows ETW and show candidate provider regions from public IP ranges.
- Inspect UDP gaps and asynchronous ICMP readings in a compact or detailed overlay.
- Mark felt lag, review local sessions, and compare two recordings over a common elapsed interval.
- Remember the overlay mode and start the network trace when eFootball is detected.
- Package portable Windows x64 builds and document how to validate them.
